Chess Academy - Run Locally in Visual Studio Code

The project is a monorepo with two workspaces:
  web/     - the React + Vite frontend (SPA)
  server/  - the Node/Express + WebSocket + LowDB backend
             (handles auth, saved games, post-game analysis notes,
             and live online games with chess clocks)

1) Install prerequisites
- Install Node.js (v20 or newer): https://nodejs.org
- Install Visual Studio Code: https://code.visualstudio.com

2) Open this project in VS Code
- In VS Code, go to File -> Open Folder
- Select: /home/runner/work/Chess-Academy/Chess-Academy
- Open a terminal in VS Code (Terminal -> New Terminal)

3) Install all dependencies (root + server + web)
- From the repository root, run:
    npm run install:all

4) Verify the repository tests
- From the repository root, run:
    npm test

5) Start both backend and frontend in dev mode
- From the repository root, run:
    npm run dev
  This starts:
    - the API + WebSocket server on http://localhost:3001
    - the Vite dev server on   http://localhost:5173
  Vite proxies /api and /ws to the backend so you only need to open
  http://localhost:5173 in your browser.

6) (Optional) Run only one workspace
- Backend only:   npm run dev:server
- Frontend only:  npm run dev:web

7) Production build of the frontend
- From the repository root, run:
    npm run build
  Output is written to web/dist/. Serve it behind any static host;
  point /api and /ws at the running backend.

8) Data storage
- The backend stores everything in server/db.json (LowDB).
  The file is created automatically on first run.
- A daily backup is written to server/db.json.bak.YYYY-MM-DD on startup.
- db.json and *.bak are gitignored.

9) Stop the app
- Press Ctrl + C in the VS Code terminal that started npm run dev.
